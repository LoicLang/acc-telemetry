# Historical documentation

This directory preserves documentation inherited from the upstream prototype and earlier diagnostic work. It is useful for implementation history, calibration evidence, and bug context, but it may describe removed entry points, old paths, or superseded architecture.

Current operational references are:

- the repository `README.md`;
- `docs/product-context.md`;
- `docs/architecture.md`;
- `docs/acc-ps5-plan.md`;
- `CONTRIBUTING.md` and `AGENTS.md`.

Do not delete a historical file merely because it is stale. Remove it only after checking active imports, tests, current documentation links, and whether it contains unique diagnostic evidence.
